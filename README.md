# 项目简介

这里介绍我在射电天文观测、望远镜控制与数字信号处理方面的项目：

- **LCT 天线控制**：面向 LCT 射电望远镜，将原有 HAU 软件与 CX9240/EtherCAT 设备接口衔接，用于状态采集、系统联调和离线模拟。
- **射电望远镜云台控制**：面向 PTS3050DZ 云台，通过 RS-485/Pelco-D 实现指向、跟踪和观测控制，并提供 Qt 上位机。
- **21 cm 氢线频谱仪**：基于 PlutoSDR，面向 1.42 GHz 中性氢谱线观测；设计采用 5 MSPS 采样、4096 点 FFT 和 4 抽头多相滤波，支持频谱显示与记录。
- **RFSoC 天文频谱读出**：基于 ZU47DR RFSoC，面向宽带中频信号采集。论文中的 RX1/RX2 双路测试采用每路 1 GSPS 采样和 4096 点 FFT，合计覆盖 2 GHz 频谱；支持频谱积分、窄带干扰抑制、数据保存和网页远程控制。
- **科研数据处理工具**：用于天文坐标计算、21 cm 频谱分析和观测站点水汽数据比较。
