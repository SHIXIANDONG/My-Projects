# 项目简介

这里介绍我在射电天文观测、望远镜控制与信号处理方面的项目：

- **LCT 天线控制**：用于 LCT 射电望远镜天线控制软件的设备接口适配、状态采集和系统联调。
- **射电望远镜云台控制**：用于云台指向、跟踪及观测控制。
- **21 cm 氢线频谱仪**：基于 PlutoSDR 采集和处理氢线频谱，支持观测、显示与记录。
- **RFSoC 天文频谱读出**：用于双路采样、频谱处理和观测数据保存。
- **科研数据处理工具**：用于天文坐标计算、频谱分析和观测环境数据处理。

本仓库仅提供项目简介，不包含源码。如需了解项目或申请访问，请联系 **230269149@seu.edu.cn**。
